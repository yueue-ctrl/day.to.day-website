# 项目内容使用说明

每个项目都是一个独立文件夹，放在 `play` 或 `pay` 目录中。

## 推荐：使用本地内容面板

在项目根目录双击 `打开内容面板.command`。浏览器会打开本地内容面板；填写文字、选择图片并点击“保存项目”后，面板会自动完成下面的文件操作。使用期间请保持弹出的终端窗口开启，完成后关闭终端窗口即可。

每次保存时，面板还会自动更新 `content/projects-data.js`。因此保存后可以直接双击根目录的 `index.html` 查看内容，不依赖本地服务器读取 JSON。

项目介绍默认开启双语自动补全：填写中文介绍会自动生成英文，填写英文介绍会自动生成中文；保存时如果缺少其中一种语言，面板也会先补全再写入项目。页面始终按中文在前、英文在后的顺序显示。其他字段和媒体注释均为单语，不进行自动翻译。翻译功能需要联网，并会把待翻译的项目介绍发送至 MyMemory 翻译服务；可以在面板中关闭。

## 新增一个项目

1. 复制对应分类中的 `_template` 文件夹。
2. 把复制后的文件夹改成项目英文短名，例如 `my-project`。只使用小写字母、数字和短横线。
3. 编辑文件夹中的 `project.json`。
4. 把首页预览图片或视频放进 `cover`，把详情页图片放进 `images`。
5. 在 `manifest.json` 的 `projects` 数组中加入项目资料路径，例如：

```json
{
  "projects": [
    "content/projects/play/my-project/project.json",
    "content/projects/pay/client-project/project.json"
  ]
}
```

## Play 与 Pay

- `play`：自主实验、研究、日常探索、非委托项目。
- `pay`：客户委托、商业合作、受雇完成的项目。

## 预览图规则

- 首页始终保留一个正方形位置。
- 首页封面支持 JPG、PNG、WEBP、GIF、MP4、WEBM 和 MOV；视频会静音、自动循环播放。
- `fit` 使用 `contain` 时，图片或视频完整显示，不裁切；长图、宽图或宽视频周围会留白。
- `fit` 改成 `cover` 时，图片或视频会铺满正方形，边缘可能被裁切。
- `background` 控制图片周围留白的颜色。
- 暂时没有预览图时，把 `src` 留空；项目名仍会显示，正方形位置也会保留。

## 内容规则

- `title`：项目名，显示在预览图左下方。
- `subtitle`：短说明，显示在预览图右下方。
- `tag`：详情页项目名下方的单语标签，例如 `Graphic / Exhibition`。
- `intro`：项目详情页的中英文简介。
- `caption`：每张详情图片、GIF 或视频自己的单语注释。
- 详情媒体支持 JPG、PNG、WEBP、GIF、MP4、WEBM 和 MOV；视频会静音循环播放，并提供播放控制。
- `alt`：给屏幕阅读器使用的图片内容说明，不要写“图片”二字。
- `published`：`true` 时出现在首页；`false` 时作为草稿保留。
- `order`：数字越小，排列越靠前。
